# Склад тканей: приложение для Android

Приложение ищет рулон по номеру и показывает, где он лежит: стеллаж и этаж. Рулоны можно добавлять, менять и удалять.
Удалённые лежат во вкладке «Удалённые», оттуда их можно вернуть при возврате.

- **Вход и регистрация.** Каждый сотрудник регистрируется сам, но только по коду, который выдаёте вы. Чужой человек зарегистрироваться не сможет.
- **Кто изменил.** У каждого рулона видно, кто его менял или удалял и когда. В карточке есть полная история.
- **Выделение.** Нажмите на рулон и подержите (или нажмите «Выбрать»), отметьте остальные и измените или удалите сразу все.
- **Общая база.** Все сотрудники видят одни и те же данные, новые изменения подтягиваются сами примерно за 10 секунд.
- **Без интернета** приложение ничего не сохраняет и пишет «Нет соединения».

Нужны бесплатные аккаунты на **supabase.com** и **github.com**. Платить не нужно.

---

## Шаг 1. Создайте базу (Supabase), около 10 минут

1. На supabase.com нажмите **Start your project** и войдите через почту или GitHub.
2. Нажмите **New project**. Название любое (например, `sklad`), придумайте пароль базы и сохраните его, регион выберите ближайший (Frankfurt). Подождите, пока проект создастся.
3. Слева откройте **SQL Editor** → **New query**. Откройте файл `supabase/schema.sql` из этой папки, скопируйте всё содержимое в окно и нажмите **Run**. Внизу должно появиться Success. Если вы запускаете файл повторно, это безопасно.

## Шаг 2. Включите регистрацию без подтверждения почты

Сотрудники входят по логину, письма им не приходят, поэтому подтверждение почты нужно отключить.

1. Слева откройте **Authentication** → **Sign In / Providers** (в некоторых версиях **Providers**) → **Email**.
2. Выключите переключатель **Confirm email** и нажмите **Save**.
3. Проверьте, что включено **Allow new users to sign up** (обычно включено по умолчанию).

## Шаг 3. Задайте код регистрации

Код вы придумываете сами и выдаёте сотрудникам. Без него зарегистрироваться нельзя.

1. **SQL Editor** → **New query**, вставьте строку ниже, замените `МОЙ_КОД` на свой код (например, `tkani2026`) и нажмите **Run**:

```sql
insert into public.app_settings (key, value) values ('signup_code', 'МОЙ_КОД')
on conflict (key) do update set value = excluded.value;
```

Чтобы поменять код позже (например, когда сотрудник уволился), запустите ту же строку с новым кодом.

## Шаг 4. Вставьте ключи в приложение

1. В Supabase откройте **Project Settings** (шестерёнка) → **API Keys** (в старых версиях **API**).
2. Скопируйте адрес проекта (**Project URL**, вида `https://abcdxyz.supabase.co`) и ключ **anon public** (или **publishable**). Это длинная строка. Секретный ключ (`service_role`, `secret`) вставлять нельзя.
3. Откройте файл `www/config.js`, замените тексты внутри кавычек и сохраните.

## Шаг 5. Соберите приложение (APK) бесплатно в облаке GitHub

1. На github.com создайте новый репозиторий, **обязательно Private** (приватный): в нём лежат ключи от базы.
2. Загрузите в него всё содержимое этой папки (**Add file → Upload files**), включая папки `.github`, `www`, `android-res` и файл `debug.keystore`. Если проводник не показывает папку `.github`, включите показ скрытых файлов. Если загружаете по частям, первые сборки могут упасть, это нормально: важна последняя.
3. Откройте вкладку **Actions**. Выберите слева **Сборка APK** → **Run workflow** (сборка может запуститься и сама после загрузки).
4. Подождите 3–10 минут, пока значок станет зелёным. Откройте самый верхний запуск, внизу в блоке **Artifacts** скачайте **sklad-apk**. Внутри архива лежит `app-debug.apk`.

Если вместо зелёного значка красный, откройте запуск, нажмите на красный шаг и пришлите текст ошибки.

## Шаг 6. Установка на телефоны

1. Отправьте `app-debug.apk` сотрудникам в мессенджере.
2. На телефоне откройте файл. Android спросит разрешение на установку из этого источника: разрешите. При предупреждении Play Protect выберите «Всё равно установить».
3. Откройте приложение, на экране входа выберите **Регистрация**, введите имя и фамилию (они будут видны в истории изменений), логин, пароль и код регистрации.

Первым зарегистрируйтесь сами, чтобы проверить, что всё работает.

## Как обновлять приложение

Если вы поменяли файлы, GitHub соберёт новый APK сам. Скачайте его и разошлите. Теперь подпись у каждой сборки одинаковая, поэтому **новую версию можно ставить поверх старой**, данные и вход сохранятся. Если Android всё равно отказывается обновлять (например, на телефоне стоит версия из более ранней сборки), один раз удалите старое приложение и установите новое.

## Если что-то не получается

- **«Supabase не принял такой логин».** Логины превращаются в служебный адрес вида `логин@sklad-tkani.com`. Если Supabase отвергает такие адреса, зарегистрируйтесь по рабочей почте (её можно вводить вместо логина) или откройте `www/config.js` и в `emailDomain` впишите домен, у которого есть почта, например домен вашей компании. Письма на него не отправляются.
- **«Аккаунт создан, но вход не разрешён».** Не выключено подтверждение почты, вернитесь к шагу 2.
- **«Не удалось зарегистрироваться. Проверьте код регистрации».** Код введён неверно или не задан (шаг 3).
- **«Не удалось подключиться к общей базе».** Проверьте интернет и значения в `config.js`: адрес должен начинаться с `https://`, ключ без пробелов.
- **Забыли пароль.** В Supabase: **Authentication** → **Users**, нажмите на сотрудника и задайте новый пароль (или удалите его и пусть зарегистрируется заново).

## Безопасность

- В базу попадают только вошедшие сотрудники. Ключ из `config.js` без входа ничего не даёт.
- Не публикуйте APK и репозиторий, передавайте их только своим людям.
- Уволенного сотрудника удалите в **Authentication → Users** и смените код регистрации (шаг 3).

## Что где лежит

- `www/index.html` — само приложение;
- `www/config.js` — адрес и ключ базы;
- `supabase/schema.sql` — таблицы, права доступа, учёт «кто изменил»;
- `android-res/` и `branding/` — иконка приложения;
- `debug.keystore` — подпись приложения (чтобы обновления ставились поверх);
- `capacitor.config.json` — название и идентификатор приложения;
- `.github/workflows/build-apk.yml` — автоматическая сборка APK на GitHub.
